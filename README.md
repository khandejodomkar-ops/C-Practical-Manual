# C++ Practical Manual

This workspace contains C++ solutions for the 12 practicals in the manual.

## Structure
- `practical_01` to `practical_12` each contain a self-contained C++ program.
- Each file is written with simple classroom-friendly code.

## Compile a practical
```bash
g++ practical_01/main.cpp -o practical_01/main.exe
./practical_01/main.exe
```

## Notes
- Programs are designed to compile with `g++` and require no external libraries.
- Practical 12 is the mini project and includes file-based persistence.
